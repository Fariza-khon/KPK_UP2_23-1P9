# Room Service (Сервис аудиторий) — Документация

## Функции сервиса

1. Создание типа аудитории.
2. Создание аудитории.
3. Привязка аудитории к типу.
4. Получение информации об аудитории по ID.
5. Получение списка аудиторий по фильтрам.
6. Обновление информации об аудитории.
7. Удаление аудитории (мягкое удаление).

## Сущности базы данных (3НФ)

### Таблица `rooms` (Аудитории)

| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
|----------|-----------|----------------|-----|-------------|----------------------|
| `id` | Уникальный идентификатор аудитории | Нет | `INTEGER` | PRIMARY KEY | Автоинкремент |
| `room_number` | Номер аудитории | Да | `VARCHAR(20)` | Уникальное значение в комбинации с `building` | — |
| `floor` | Этаж расположения аудитории | Да | `INTEGER` | ≥ 1 | — |
| `building` | Название корпуса | Да | `VARCHAR(50)` | — | — |
| `capacity` | Вместимость аудитории | Да | `INTEGER` | > 0 | — |
| `is_active` | Флаг активности аудитории (soft delete) | Нет | `BOOLEAN` | — | `TRUE` |

### Таблица `room_types` (Типы аудиторий)

| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
|----------|-----------|----------------|-----|-------------|----------------------|
| `id` | Уникальный идентификатор типа аудитории | Нет | `INTEGER` | PRIMARY KEY | Автоинкремент |
| `type_name` | Название типа аудитории | Да | `VARCHAR(50)` | UNIQUE | — |

### Таблица `room_room_type` (Связь аудиторий и типов)

| Параметр | Пояснение | Обязательность | Тип | Ограничение |
|----------|-----------|----------------|-----|-------------|
| `room_id` | Ссылка на аудиторию | Да | `INTEGER` | PRIMARY KEY, FOREIGN KEY → `rooms.id`<br>ON DELETE CASCADE |
| `room_type_id` | Ссылка на тип аудитории | Да | `INTEGER` | PRIMARY KEY, FOREIGN KEY → `room_types.id`<br>ON DELETE CASCADE |

**Индексы для оптимизации:**
- `idx_room_id` — для ускорения запросов по аудитории
- `idx_room_type_id` — для ускорения запросов по типу аудитории

### 5. Добавить аудиторию

**Endpoint:** `POST /rooms/`

**Информация для создания:**

| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
|----------|-----------|----------------|-----|-------------|----------------------|
| `room_number` | Номер аудитории | Да | `string` | Уникальное значение в комбинации с `building` | — |
| `floor` | Этаж расположения | Да | `integer` | ≥ 1 | — |
| `building` | Корпус | Да | `string` | — | — |
| `capacity` | Вместимость (кол-во мест) | Да | `integer` | > 0 | — |
| `type_ids` | Список ID типов аудитории | Нет | `array` of `integer` | Должны существовать в `room_types` | `[]` |

**Уникальные комбинации параметров:**
- `room_number` + `building` должны быть уникальными.

**Информация, возвращаемая в случае успешного создания:**

| Параметр | Пояснение | Тип |
|----------|-----------|-----|
| `id` | Уникальный идентификатор | `integer` |
| `room_number` | Номер аудитории | `string` |
| `floor` | Этаж | `integer` |
| `building` | Корпус | `string` |
| `capacity` | Вместимость | `integer` |
| `is_active` | Статус активности аудитории | `boolean` |
| `types` | Типы аудитории | `array` of `RoomTypeResponse` |

### 9. Получить список аудиторий по заданным параметрам

**Endpoint:** `GET /rooms/`

**Параметры фильтрации:**

| Параметр | Пояснение | Тип | Описание |
|----------|-----------|-----|----------|
| `building` | Фильтр по корпусу | `string` | Частичное совпадение (опционально) |
| `floor` | Фильтр по этажу | `integer` | Точное совпадение (опционально) |
| `min_capacity` | Минимальная вместимость | `integer` | `capacity >= min_capacity` (опционально) |
| `type_id` | Фильтр по типу аудитории | `integer` | Возвращает аудитории, имеющие указанный тип (опционально) |
| `is_active` | Фильтр по статусу активности | `boolean` | `true`/`false` (опционально) |
| `skip` | Пагинация (пропустить) | `integer` | ≥ 0, по умолчанию 0 |
| `limit` | Пагинация (лимит) | `integer` | 1-100, по умолчанию 20 |

**Правила обработки параметров:**
- Если параметры фильтрации не заданы, возвращаются все активные аудитории (`is_active = true`).
- При некорректных значениях (`min_capacity < 0`, `floor < 1`, `limit > 100` и т.д.) возвращается ошибка валидации.
- Если `type_id` указан и не существует, возвращается пустой список.

**Информация, возвращаемая в виде списка:**

| Параметр | Пояснение | Тип |
|----------|-----------|-----|
| `id` | Уникальный идентификатор | `integer` |
| `room_number` | Номер аудитории | `string` |
| `floor` | Этаж | `integer` |
| `building` | Корпус | `string` |
| `capacity` | Вместимость | `integer` |
| `is_active` | Статус активности аудитории | `boolean` |
| `types` | Типы аудитории | `array` of `RoomTypeResponse` |
