Вариант №17. Room Service (Сервис аудиторий)


## Функции сервиса

1. Создание типа аудитории.
2. Создание аудитории.
3. Привязка аудитории к типу.
4. Получение информации об аудитории по ID.
5. Получение списка аудиторий по фильтрам.
6. Обновление информации об аудитории.
7. Удаление аудитории.


## ER‑диаграмма

![ER‑диаграмма](erd.png)

**Сущности:**

## Таблица `rooms` (Аудитории)

| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
|--------|----------|--------------|------|-------------|--------------------|
| `id` | Уникальный идентификатор аудитории | Нет | `INT` или `SERIAL` | **PRIMARY KEY** | Автоматически |
| `room_number` | Номер аудитории | Да | `VARCHAR(20)` | Уникальное значение в комбинации с `building` | — |
| `floor` | Этаж расположения аудитории | Да | `INT` | ≥ 1 | — |
| `building` | Название корпуса | Да | `VARCHAR(50)` | — | — |
| `capacity` | Вместимость аудитории | Да | `INT` | > 0 | — |
| `is_active` | Флаг активности аудитории (soft delete) | Нет | `BOOLEAN` | — | `TRUE` |

## Таблица `room_types` (Типы аудиторий)

| Параметр | Пояснение | Обязательность | Тип | Ограничение | Значение по умолчанию |
|--------|----------|--------------|------|-------------|--------------------|
| `id` | Уникальный идентификатор типа аудитории | Нет | `INT` или `SERIAL` | **PRIMARY KEY** | Автоматически |
| `type_name` | Название типа аудитории | Да | `VARCHAR(50)` | **UNIQUE** (не допускает дублирования названий) | — |

## Таблица `room_room_type` (Связь аудиторий и типов)

| Параметр | Пояснение | Обязательность | Тип | Ограничение |
|--------|----------|--------------|------|-------------|
| `room_id` | Ссылка на аудиторию | Да | `INT` | **FOREIGN KEY** → `rooms.id`<br>**ON DELETE CASCADE**<br>**NOT NULL** |
| `room_type_id` | Ссылка на тип аудитории | Да | `INT` | **FOREIGN KEY** → `room_types.id`<br>**ON DELETE CASCADE**<br>**NOT NULL** |

**Составной PRIMARY KEY:** (`room_id`, `room_type_id`) — гарантирует уникальность каждой пары «аудитория‑тип».

**Индексы для оптимизации:**
* `INDEX idx_room_id (room_id)` — для ускорения запросов по аудитории;
* `INDEX idx_room_type_id (room_type_id)` — для ускорения запросов по типу аудитории.


### 1. Добавить аудиторию (POST /rooms/)

**Информация для создания:**

| Параметр | Пояснение | Обязательность | Тип | Ограничение |
|--------|----------|--------------|------|-------------|
| `room_number` | Номер аудитории | Да | string | Уникальное значение |
| `floor` | Этаж расположения | Да | integer | ≥ 1 |
| `building` | Корпус | Да | string | — |
| `capacity` | Вместимость (кол‑во мест) | Да | integer | > 0 |
| `type_ids` | Список ID типов аудитории | Нет | array of integers | Должны существовать в RoomTypes |

**Уникальные комбинации параметров:**
- `room_number` + `building` должны быть уникальными.

**Информация, возвращаемая в случае удачного создания аудитории:**

| Параметр | Пояснение | Тип |
|--------|----------|------|
| `id` | Уникальный идентификатор | integer |
| `room_number` | Номер аудитории | string |
| `floor` | Этаж | integer |
| `building` | Корпус | string |
| `capacity` | Вместимость | integer |
| `is_active` | Статус активности аудитории | boolean |
| `types` | Типы аудитории | array of RoomTypeResponse |


### 2. Изменить аудиторию по ID (PUT /rooms/{room_id})

**Информация для изменения:**

| Параметр | Пояснение | Обязательность | Тип | Ограничение |
|--------|----------|--------------|------|-------------|
| `room_number` | Новый номер аудитории | Нет | string | Если указан, должен быть уникальным в комбинации с `building` |
| `floor` | Новый этаж | Нет | integer | ≥ 1 |
| `building` | Новый корпус | Нет | string | — |
| `capacity` | Новая вместимость | Нет | integer | > 0 |
| `type_ids` | Новые ID типов | Нет | array of integers | Должны существовать в RoomTypes |
| `is_active` | Статус активности | Нет | boolean | — |

**Информация, возвращаемая в случае удачного изменения аудитории:**

| Параметр | Пояснение | Тип |
|--------|----------|------|
| `id` | Уникальный идентификатор | integer |
| `room_number` | Номер аудитории | string |
| `floor` | Этаж | integer |
| `building` | Корпус | string |
| `capacity` | Вместимость | integer |
| `is_active` | Статус активности аудитории | boolean |
| `types` | Типы аудитории | array of RoomTypeResponse |


### 3. Удаление аудитории по ID (DELETE /rooms/{room_id})

Вернет `True`, если аудитория была деактивирована (мягкое удаление), иначе вернет `False`.
